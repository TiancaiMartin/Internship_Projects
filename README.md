## Overview

This repository documents my workflow for **quantitative strategy research and evaluation**:

- **Signal idea generation** (macro / technical / statistical relationships)
- **Data processing & feature engineering**
- **Modeling** (statistical + machine learning)
- **Backtesting & diagnostics**
- **Iteration & strategy refinement**

It is intended as a research portfolio for graduate admissions and professional review.
