# CTA-Based Asset Management Strategies

## Overview

This project explores systematic CTA-style strategies based on trend-following and rule-based portfolio allocation.

It focuses on constructing disciplined, signal-driven strategies across multiple assets with emphasis on robustness and risk-adjusted evaluation.

---

## Objective

- Design trend-following signals
- Implement rule-based portfolio construction
- Evaluate multi-asset allocation performance
- Compare variants under rolling evaluation

---

## Strategy Components

### 1. Trend Signal Construction
- Moving-average based signals
- Momentum filters
- Volatility adjustments

### 2. Allocation Logic
- Equal-weight vs signal-weighted
- Risk scaling options
- Periodic rebalancing

### 3. Risk Control
- Drawdown monitoring
- Volatility filtering
- Position sizing constraints

---

## Backtesting Design

- Rolling performance evaluation
- Cumulative return analysis
- Risk-adjusted metrics
- Strategy comparison under consistent assumptions

## Key Strengths Demonstrated

- Signal discipline
- Risk-aware allocation
